## Deploy using Terraform

### Prerequisites

1. **For Windows Users**: Install Windows Subsystem for Linux (WSL). For detailed installation steps, refer to the [official documentation](https://learn.microsoft.com/en-us/windows/wsl/install).
2. **Terraform Installation**: Install Terraform by following the instructions provided in the [Official Terraform documentation](https://developer.hashicorp.com/terraform/install).
3. Ensure that the values of vm_count and vm_config in the example.tfvars file are consistent when creating new VMs.

### STEP 1

#### 1.1 VM can be creted by passing userdata from a text file. This text file will be generated by setting value of variable use_userdata as true and then executing the following script:

##### Export Environment Variables for QualysGuard Authentication

```shell
export QUALYSGUARD_LOGIN="your_qualysguard_username"
export QUALYSGUARD_PASSWORD="your__qualysguard_password"
./get_activation_token.sh <PATH_TO_TFVARS_FILE(paramter file)>
```

##### See parameter file examples in the 'example.tfvars' file

#### 1.2 VM can be created by directly populating vApp parameters from a parameters file by setting use_userdata as false.

Example:
./get_activation_token.sh example/existing_resource.tfvars

### STEP 2

```shell
terraform init 
terraform plan -var-file=<PATH_TO_TFVARS_FILE>
terraform apply -var-file=<PATH_TO_TFVARS_FILE>
```

### Parameters

| Parameter                        | Input Value                           | Description                                                                                                                                                        |
|----------------------------------|----------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `user`                           | vSphere username                       | Username to authenticate with vSphere.                                                                                                                             |
| `password`                       | vSphere password                       | Password to authenticate with vSphere.                                                                                                                             |
| `vsphere_server`                | vSphere server URL                | vSphere server URL. Example: `vcn123.test.com`.                                                                                                               |
| `remote_ovf_path`               | OVA Path                        | Remote path to the OVA file.                                                                                                                              |
| `datacenter`                    | vSphere datacenter name                | Name of the datacenter in vSphere where VMs will be deployed.                                                                                                      |
| `compute_cluster`               | Cluster name                           | Name of the target compute cluster.                                                                                                                                |
| `datastore`                     | Datastore name                         | Name of the datastore used for VM storage.                                                                                                                         |
| `lan_network`                   | Network name                           | LAN network name to attach to the VM.                                                                                                                              |
| `wan_network`                   | Network name                           | WAN network name to attach to the VM.                                                                                                                              |
| `vsphere_host`                  | Host IP address                        | vSphere ESXi host IP where VM will be deployed.                                                                                                                    |
| `disk_provisioning`            | `thin` or `thick`                      | Disk provisioning method.                                                                                                                                          |
| `disk_label`                    | Disk label                             | Label for the VM disk.                                                                                                                                             |
| `disk_size`                     | Disk size (e.g., `60`)                 | Disk size in GB.                                                                                                                                                   |
| `adapter_type`                 | Adapter type (e.g., `vmxnet3`)         | Network adapter type.                                                                                                                                              |
| `vm_count`                      | Number                                 | Number of VMs to deploy (e.g., `1`).                                                                                                                               |
| `friendly_name`                | Name prefix                            | Friendly name for the scanner VM(s).                                                                                                                               |
| `num_cpus`                      | Number of CPUs                         | Number of virtual CPUs per VM.                                                                                                                                     |
| `memory`                        | Memory in MB                           | Memory size allocated to the VM (in MB).                                                                                                                           |
| `enable_WAN_interface`          | `True` or `False`                      | Whether to enable the WAN interface.                                                                                                                               |
| `HTTP_Proxy`                   | Proxy string                           | HTTP proxy string for the VM.                                                                                                                |
| `LAN_IP`                        | IP address                             | Static LAN IP address.                                                                                                                                             |
| `qualysguard_url`              | URL string                             | QualysGuard platform URL (e.g., `qualysguard.qualys.com`).                                                                                                         |
| `LAN_Gateway`                  | IP address                             | Gateway IP for the LAN network.                                                                                                                                    |
| `LAN_Default_VLAN`             | VLAN ID                                | VLAN ID used in LAN configuration.                                                                                                                                |
| `IPV6_ONLY`                    | `True` or `False`                      | Indicates if the VM should use only IPv6.                                                                                                                          |
| `LAN_DNS_Servers`              | DNS IP(s)                              | DNS servers for the LAN network.                                                                                                     |
| `WAN_IP`                        | IP address                             | Static IP address for the WAN interface.                                                                                                                           |
| `WAN_Gateway`                  | IP address                             | Gateway IP for the WAN network.                                                                                                                                    |
| `WAN_DNS_Servers`              | DNS IP(s)                              | DNS servers for the WAN network (comma-separated if multiple).                                                                                                     |
| `PREFER_USERDATA`              | `True` or `False`                      | Whether to prefer cloud-init based configuration via `userdata.txt`.                                                                                              |
| `LAN_Netmask`                  | Subnet mask                            | Netmask for the LAN network.                                                                                                                                       |
| `WAN_Netmask`                  | Subnet mask                            | Netmask for the WAN network.                                                                                                                                       |
| `WINS_1`                        | WINS server IP                         | Primary WINS server.                                                                                                                                               |
| `WINS_2`                        | WINS server IP                         | Secondary WINS server.                                                                                                                                             |
| `WINS_DOMAIN`                  | Domain name                            | WINS domain name.                                                                                                                                                  |
| `use_userdata`                 | `True` or `False`                      | Whether to use cloud-init `userdata` in VM deployment.                                                                                                             |

### Destroy Resources(vm's)

Command to sedtroy recources created via terraform templtes:
```shell
terraform init 
terraform plan -destroy -var-file=<PATH_TO_TFVARS_FILE>
terraform apply -destroy -var-file=<PATH_TO_TFVARS_FILE>
```
